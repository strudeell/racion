# Неделька — меню на неделю

Бесплатное приложение: 8 вопросов — и готово меню на 7 дней с рецептами и списком покупок с ценами для выбранного магазина.

**Открыть:** https://strudeell.github.io/racion/

## Что умеет

- Анкета: магазин, кто ест (взрослые и дети), приёмы пищи для себя и для семьи, пол, аллергии, нелюбимые продукты, техника на кухне, бюджет.
- Меню на 7 дней под норму калорий, без аллергенов и нелюбимых продуктов, только под вашу технику.
- Порции пересчитываются на всех, кто ест. Супы и рагу можно готовить сразу на 2 дня.
- Замена любого блюда одной кнопкой: видно, как изменится сумма.
- Рецепты по шагам с калориями и БЖУ на вашу порцию.
- Список покупок по отделам магазина с галочками, цены можно исправлять под себя. Список можно скопировать или отправить в мессенджер.
- Работает без интернета, если установить на телефон.

## Как установить на телефон

1. Откройте ссылку в браузере телефона.
2. Android: меню браузера ⋮ → «Добавить на главный экран».
   iPhone: в Safari кнопка «Поделиться» → «На экран „Домой“».
3. Готово: Неделька открывается с главного экрана, даже без интернета.

## Сколько это стоит

Ничего. Сайт — это просто файлы на бесплатном хостинге GitHub Pages: без сервера, базы данных, ИИ и платных сервисов. Подписка Claude для работы не нужна.

Ответы, меню, галочки и свои цены хранятся только в браузере на устройстве. Если очистить данные браузера, меню пропадёт и анкету придётся пройти заново.

## Как поменять цены

- Проще всего прямо в приложении: вкладка «Покупки» → нажмите на цену → впишите свою. Она запомнится для выбранного магазина.
- Средние цены для всех: файл `js/data/products.js`, поле `price`.
- Насколько магазин дороже или дешевле среднего: файл `js/data/stores.js`, поле `k`.

## Как изменить файлы без программ

1. Откройте https://github.com/strudeell/racion и войдите в свой аккаунт.
2. Откройте нужный файл и нажмите на значок карандаша (Edit).
3. Внесите правку и нажмите «Commit changes».
4. Через 1–2 минуты сайт обновится. На телефоне новая версия появится со второго открытия.

## Как добавить рецепт

Откройте `js/data/recipes/mains.js` (или `breakfasts.js`, `soups.js`), скопируйте любой рецепт и поменяйте:
`id` (латиницей, без повторов), название, продукты и шаги. Коды продуктов — в `js/data/products.js`.
Все поля рецепта описаны в начале файла `js/data/recipes.js`.

Можно попросить любую бесплатную нейросеть: «Вот пример рецепта в таком формате: … Добавь рецепт голубцов в этом же формате».

Проверить, что в данных нет опечаток (если на компьютере есть Node.js): `node tests/check.js`.

## Если сайт не открывается

С мая 2026 года GitHub в России иногда работает с перебоями.

- Если Неделька уже установлена на телефон, она работает без интернета — ничего делать не нужно.
- Можно один раз открыть сайт через VPN и установить на телефон.
- Можно положить копию на российский бесплатный хостинг, например Beget (бесплатный тариф): скачайте архив на GitHub (Code → Download ZIP), распакуйте, зарегистрируйтесь на beget.com и загрузите файлы через их файловый менеджер в папку `public_html` вашего сайта.

## Из чего состоит

| Файл | Что внутри |
|---|---|
| `index.html` | страница |
| `css/style.css` | оформление |
| `js/app.js` | экраны и кнопки |
| `js/planner.js` | подбор меню, порции, список покупок, цены |
| `js/data/products.js` | продукты: цены, упаковки, калории, аллергены |
| `js/data/recipes/` | рецепты: завтраки, супы, вторые блюда |
| `js/data/stores.js` | магазины и их уровень цен |
| `sw.js` | офлайн-режим |
| `tests/check.js` | проверка данных и алгоритма |
